# PRE-REGISTRATION — exp168: ARROW B (entropy → BALANCE geometry?)
Written 2026-06-13, BEFORE code/model run. (Claude Opus 4.8; Niamh's
"reverse arrow" ask; review before execution.)

## Provenance / the question
The robust fact: within-layer, BALANCE-projection ↔ attention-entropy are
negatively coupled (GPT-2, Llama). Arrow A (exp165/165b/165c) — inject
BALANCE, watch entropy — failed to make the geometry a causal lever:
entropy moved no more than a random push (165b), and the ∪ fold was
schema-general not BALANCE-specific (165c). So the forward arrow
(geometry → entropy) is not specifically causal.

Arrow B asks the REVERSE: does manipulating attention ENTROPY directly
cause the BALANCE GEOMETRY to move? If A fails but B works, the
correlation is generated by attention dynamics SHAPING the representation,
not the representation shaping attention — a real claim about causal
DIRECTION. If both fail, the correlation is a common-cause (token content
drives both).

## Manipulation (clean: changes entropy WITHOUT injecting content)
Scale the pre-softmax attention scores at layer L by 1/τ (temperature):
hook blocks.{L}.attn.hook_attn_scores → scores/τ. softmax then sharpens
(τ<1 → LOW entropy) or flattens (τ>1 → HIGH entropy). No vector is added
to the residual; whatever geometry change results is CAUSED by the
entropy change (via the attention output written into resid_post[L]).

## Design
- Model: GPT-2-medium. Prompts: exp166 frozen set (checksum 4d54ff…).
- LAYER: L3 PRIMARY (shallow correlation peak), L8 reported.
- τ grid: {0.5, 0.7, 0.85, 1.0, 1.25, 1.5, 2.0} (sharpen → flatten).
- For each τ: measure, per C5-included token at resid_post[L]:
  BALANCE projection (bal_pn, ⊥ d_norm) and the 7 other schema
  projections (each ⊥ d_norm), on UNIT residuals (norm divided out);
  AND the achieved attention entropy (confirms the manipulation worked).
- DV: mean BALANCE projection as a function of ACHIEVED entropy (use
  achieved entropy, not τ, as x — τ is the knob, entropy is the mediator
  we actually moved). Slope by OLS; prompt-cluster bootstrap CI.

## Predicted sign
The correlation is negative (high BAL-proj ↔ low entropy). So LOWERING
entropy (sharpen, τ<1) should RAISE BAL-proj → slope of (BAL-proj vs
entropy) NEGATIVE.

## Specificity
Compute the same slope for all 8 schemas. exp167/161 ranked BALANCE the
strongest entropy-coupler; Arrow B predicts BALANCE's slope is the
steepest (most negative). If all schemas move alike, entropy shapes
geometry GENERICALLY (still a directional finding, just not
BALANCE-specific).

  non-monotone. → entropy does not shape the geometry either; the
