# The audit of 2–3 October 2026, and what came after

On 2–3 October 2026 an audit of this project found two faults in the
instrument behind several published findings, and a third problem with
how results were judged:

1. **No start token in Pythia.** Single words were run alone, so they sat
   at position 0, where the model's states are far larger and behave
   differently. See `START_TOKEN_BUG_2026-10-02.md`.
2. **Whole words against word fragments.** In several word lists one end
   was mostly single whole-word tokens and the other mostly words split
   into pieces, so a "schema" direction was partly a whole-word-versus-
   fragment direction.
3. **The wrong baseline.** Directions built from random words correlate
   with model internals at |r| 0.2–0.3; results had been judged against
   zero.

Every experiment from exp174 on was pre-registered before it ran, with
its decision rule and committed odds, then graded. The pre-registrations
are in `../prereg/` (PREREG_exp174.md to PREREG_exp203.md, and
PILOT_exp197), the scripts in `../experiments/`, the stimuli in
`../data/`, the raw outputs and result files in `../results/`.

**Short version.** Withdrawn: the suffix sink onto BALANCE, the
transformer-versus-word2vec contrast built on it, BALANCE coupled to the
residual norm and to attention entropy, and the causal-direction and
checkpoint results built on those. Survived: HAPPY IS UP (clean steering,
beyond every random-word direction, in Pythia 1.4B and GPT-2 medium;
exp187, exp194, exp203) and the predicted schema system (exp192). New:
source-path-goal structure learned from literal journeys reads abstract
change and the input and output of instructions (exp198, exp199), and it
is relational (exp200). In progress: what happens to an instruction's
goal while the model carries it out (exp201, exp202).

Some scripts read cached activations (`*.npz`) that are too large for the
repository; they are regenerated by the scripts that write them. Paths in
the scripts are those of the machine the work was done on.
